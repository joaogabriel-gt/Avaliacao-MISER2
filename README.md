## Objetivo 
Organizar, versionar, conteinerizar e provisionar uma aplicacao web utilizando praticas de DevOps e infraestrutura como codigo. 
 
## Tecnologias utilizadas 
- Git 
- Docker 
- Docker Compose 
- Terraform 
- Nginx 
- GitHub 
 
## Executar a aplicacao 
 
```bash 
docker compose up -d 
``` 
 
Acesse: 
http://localhost:8080 
 
Para encerrar: 
 
```bash 
docker compose down 
```
